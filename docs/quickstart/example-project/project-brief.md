# 故事前提

每逢无月潮，海边旧灯塔都会熄灭。十二岁的阿澈在退潮后的礁石缝里捡到一封没有寄件人的信，信里准确写着明天将发生的事情。灯塔守人海爷爷不肯解释，修理工具却在夜里被人搬进了封锁的地下仓库。阿澈和伙伴小满必须在下一次涨潮前找回灯芯，同时判断写信的人是在求救，还是在把他们引向危险。

## 第一章任务

- 建立灯塔熄灭的异常；
- 让阿澈获得第一封预言信；
- 让阿澈和小满决定调查地下仓库；
- 保留“谁知道灯塔会熄灭”的未解悬念；
- 结尾不要解释寄信人身份。

## 写作边界

- 基调是克制的海边悬疑，不使用血腥细节；
- 每章至少推进一个外部行动和一个人物选择；
- AI 只能提出候选内容，作者确认后才成为故事事实；
- 不把未来大纲当作已经发生的正文。
