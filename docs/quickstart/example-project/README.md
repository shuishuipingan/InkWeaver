# 灯塔来信：InkWeaver 无版权示例

“灯塔来信”是一个用于演示连续写作的原创短篇样例。它故意保留一个章节末尾的未解问题，让你可以在第二章看到上一章定稿如何成为下一章的事实来源。

## 文件

- `project-brief.md`：故事前提、读者期待和创作边界；
- `story-bible.md`：世界规则、角色、关系和已确认事实；
- `outline.md`：六章大纲与主线/支线目标；
- `chapters/chapter-01.md`：可直接导入或粘贴的第一章示例。

## 使用方式

1. 在桌面版中新建“灯塔来信”项目。
2. 参考这些 Markdown 文件填入设定和章节蓝图。
3. 生成候选草稿，逐项审阅证据，再由作者定稿。
4. 打开第二章写前摘要，观察“门后第二封信”如何作为未解悬念继续存在。

这些文本只用于产品演示，采用 InkWeaver 项目示例许可，不代表任何真实作品、人物或事件。请不要把 API Key、私人原稿或真实人物信息加入公共仓库。
