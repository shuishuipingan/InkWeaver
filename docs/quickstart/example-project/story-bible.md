# 故事圣经

## 世界规则

1. 灯塔使用一枚旧鲸油灯芯，只有海爷爷知道完整的更换方法。
2. 无月潮每七天出现一次，潮水退到黑礁线时，灯塔附近的无线电会短暂失灵。
3. 预言信只描述即将发生的可观察事件，不会直接写出完整真相。
4. 地下仓库在第一章结束时仍未被打开；任何仓库内部信息都属于未来计划，不是当前事实。

## 角色

### 阿澈

- 年龄：十二岁；
- 目标：找回灯芯并弄清第一封信的来源；
- 当前状态：好奇但害怕让海爷爷失望；
- 已知信息：只知道灯塔熄灭和信中写出的潮汐时间；
- 不知道：海爷爷曾在二十年前收到过相同格式的信。

### 小满

- 年龄：十三岁；
- 目标：保护阿澈，不让他独自进入地下仓库；
- 当前状态：带着修理工具，擅长观察锁和脚印；
- 已知信息：看见有人在黄昏后搬动工具箱；
- 不知道：寄信人是否仍在岛上。

### 海爷爷

- 身份：灯塔守人；
- 目标：让灯塔继续工作，并隐藏旧信的来历；
- 当前状态：疲惫、隐瞒、仍愿意保护孩子；
- 已确认秘密：二十年前的旧信被锁在地下仓库。

## 第一章结束时的权威事实

- 灯塔已经熄灭；
- 阿澈收到第一封无寄件人信；
- 小满知道有人搬动工具箱；
- 阿澈和小满决定在下一次涨潮前调查地下仓库；
- 地下仓库尚未打开；
- “第二封信是否已经在仓库里”是下一章的未解问题。
