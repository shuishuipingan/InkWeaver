# 第一章 潮汐退去

灯塔是在下午四点十七分熄灭的。

阿澈正在码头收晾鱼网，听见远处传来一声闷响，抬头时只看见灯塔顶端的玻璃窗暗了下去。那盏灯平时像钉在天边的星，哪怕白天也能看见微弱的金色。今天它消失得太突然，连海面都像跟着沉了一寸。

“别过去。”小满拽住他的袖子，“海爷爷说过，无月潮前不能靠近黑礁线。”

可阿澈已经看见礁石缝里夹着一只湿透的信封。信封没有邮票，没有寄件人，纸角却干净得像刚从屋里拿出来。他拆开信，里面只有一句话：

> 潮水退到第三根系缆桩时，灯会熄灭；不要让守灯人打开仓库。

第三根系缆桩旁的水痕正在往后退。阿澈数了三遍，信上的时间和眼前分毫不差。

海爷爷从灯塔方向走来，手里没有修理工具，只握着一把旧铜钥匙。他看见信纸时脸色变了，随后把钥匙藏进袖口。

“这不是给你们的东西。”他说。

小满没有回答。她蹲在湿沙上，用指尖拨开一截断草，露出两道新鲜的拖痕，一直通向灯塔后方那扇多年没有打开的铁门。门内传来轻轻的碰撞声，像有人在黑暗里放下了第二只箱子。

远处的潮线停了一瞬，又继续退去。

阿澈把信折好放进口袋，第一次没有听海爷爷的话。他和小满约定，下一次涨潮前找到灯芯，也要弄清楚那扇门后面究竟有没有第二封信。

**本章未解问题：**谁提前知道灯会熄灭？地下仓库里的箱子是谁搬来的？
