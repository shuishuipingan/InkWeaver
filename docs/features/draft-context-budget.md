# 长篇写作的资料选择与预算

## 生成前看什么

AI 输出面板的“写前上下文收据”会列出本次资料。展开后可查看完整、摘要、未纳入、来源类型及摘要缓存命中。人物核心、背景细节与人物状态分别显示；未核实/未来状态会给出未纳入原因。长列表支持滚动。

“写前预算”显示估算输入、当前输入上限、输出预留和模型上下文容量。Token 数是 UTF-8 文本的保守估算，并非各模型专用 tokenizer 的精确计数。角色资料、正文和提示词不会写入预算日志。

## 资料保护与筛选

本章显式出场或事件提及的人物保留核心档案，包括身份、外貌、性格、能力、动机、关系、备注和约束。相关非出场人物优先选直接关系，再考虑相关地点、势力，最多 12 人。其他人物不整表发送。

背景、人物弧线及全书架构可使用完整句段的摘录摘要。原始资料仍保存在项目中；约束句保留。无法安全分割的超长段落会保留完整，由预算预检决定是否能发送。

定稿连续性与实际定稿正文用于前文事实；草稿是候选资料。参考书片段只作风格、结构参考，未来蓝图是规划。续写也继承本章人物核心和全书设定，显示对应请求实际使用的资料。

## 预算不足时

已配置模型容量时，可用输入为上下文容量扣除输出预留和安全余量，再受应用 96,000 估算输入 Tokens 上限约束。容量未知时使用 16,384 的保守输入上限。

必保资料无法完整容纳时，会在模型请求前阻止生成并显示保护区段。可在模型设置的“上下文窗口”中填写与实际服务一致的能力上限，或选择更大容量模型；也可调整本章范围、精简角色核心说明。未知容量的保守预算不能证明任意网关都支持该窗口，请以所用服务的配置为准。

输出预留按章节目标计算，受模型输出能力与本次任务剩余额度约束。高容量模型不会自动获得无限输入或输出。

## 缓存何时更新

摘录摘要按依赖的源文本、章节、相关词和算法版本绑定。相关资料或选择条件改变后，不匹配的旧摘要不会命中。每项目最多 128 条，单条最多 32 KiB。缓存是可重新生成的派生资料，不修改角色卡、正文或定稿事实，也不增加模型调用。
