# 织墨 / InkWeaver

织墨是一款面向长篇小说创作的本地优先桌面工作台。它把项目设定、角色、世界观、章节蓝图、正文、审稿、修订和定稿连接成可追溯的创作流程，并允许作者接入自己的本地或云端模型。
